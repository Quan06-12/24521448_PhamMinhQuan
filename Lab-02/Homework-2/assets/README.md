# Local audio

These three original short instrumentals are generated by `../scripts/generate-audio.mjs`. Run `npm run generate:audio` from Homework-2 to reproduce the checked-in WAV bytes. There are no external samples, URLs or licenses to fetch.

Format: 22,050 Hz, mono, signed 16-bit PCM WAV. Track duration, pitch and tempo are declared in the generator; the catalog is `../src/tracks.js`. Peak synthesis amplitude is bounded below clipping and each piece fades in/out.
