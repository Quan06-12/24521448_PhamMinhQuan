# Homework 2 project rules

- Follow the parent Lab-02/project-rules.md. Scope this homework to native ES modules; existing Exercise VDOM implementations remain unchanged.
- Define contracts before implementation; keep preparation, queue ownership, visualization and UI in separate modules.
- Use semantic elements, safe text APIs, delegated events, visible focus and responsive layouts.
- Keep CSS selectors shallow and use a small neutral/teal palette with a single error color.
- Never publish per-frame canvas values to UI state. Never retain buffers or connected sources after a task ends.
- Record only reproducible defects actually found by independent review in AI_FAILURE_AUDIT.md. Do not introduce defects to fill the audit.
- Review every functional slice independently before a Conventional Commit. Keep test output and screenshots under ignored evidence/.
- No dependency folders, build output or evidence are tracked. Local demo audio is deterministic source material generated by the included script.
