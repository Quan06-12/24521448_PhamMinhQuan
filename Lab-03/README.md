# Lab 03 – Production React 19, Fiber Hooks & Concurrent UI

## Overview
This lab upgrades the Lab 02 Mini-React engine to production React 19 (Vite):
`createRoot`, pure functional components, `useState` immutability, derived state,
`useId` accessible forms, `useEffect` cleanup and 4-state async machines.
