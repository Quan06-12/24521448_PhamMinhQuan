# Project Rules

## Technology
- Use HTML5, CSS3, and Vanilla JavaScript ES6+.
- Do not use Bootstrap, Tailwind, React, or jQuery.
- Use external CSS and JavaScript files.

## HTML
- Use semantic HTML elements.
- Use only one h1 per page.
- Include a skip link.
- Avoid unnecessary div elements.
- Use accessible labels for form controls.

## CSS
- Use mobile-first design.
- Support a 375px viewport.
- Use simple CSS selectors.
- Use CSS variables for colors.
- Use Flexbox and Grid for layouts.

## JavaScript
- Use const by default.
- Use addEventListener instead of inline onclick.
- Store theme preference in localStorage.
- Never insert untrusted user input using innerHTML.

## Git
- Make atomic commits.
- Separate HTML, CSS, and JavaScript tasks.
- Review git diff before committing.
